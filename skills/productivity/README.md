# Productivity

Promoted skills for general workflow, thinking, and productivity tasks.

Skills in this bucket are public, stable, and documented. They are not necessarily code-specific.

## User-invoked

- [`ask-skills`](./ask-skills/SKILL.md) — Ask which skill or workflow fits the current situation.

## Model-invoked

None yet.

## Promotion requirements

Every promoted productivity skill must have:

- `SKILL.md`
- `agents/openai.yaml`
- an entry in this README
- an entry in the root README
- a human-facing docs page under `docs/productivity/<skill>.md`
