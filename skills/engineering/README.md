# Engineering

Promoted skills for daily software engineering work.

Skills in this bucket are public, stable, and documented. They should be useful across many repositories and coding agents.

## User-invoked

None yet.

## Model-invoked

Initial engineering skills will be added in a later feature slice.

## Promotion requirements

Every promoted engineering skill must have:

- `SKILL.md`
- `agents/openai.yaml`
- an entry in this README
- an entry in the root README
- a human-facing docs page under `docs/engineering/<skill>.md`
